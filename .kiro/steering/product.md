# Product Overview

Negarin is an open-source, federated photo sharing platform that provides an ethical alternative to centralized social media platforms. It's built on ActivityPub federation protocol, allowing users to share photos across the fediverse.

## Key Features
- Photo sharing with privacy controls
- ActivityPub federation support
- Stories and collections
- Direct messaging
- User profiles and following system
- Admin panel for instance management
- Mobile-responsive web interface
- API for third-party clients

## Target Audience
- Individuals seeking privacy-focused photo sharing
- Communities wanting to self-host their social platform
- Developers building federated social applications
